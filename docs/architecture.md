# Architecture

## Logical Flow

```text
Source Data
    |
    v
Backup Script
    |
    v
Backup Storage
    |
    v
Restore Script
    |
    v
Restore Target
```

## Components

### Source Data

Каталог с тестовыми файлами, имитирующими рабочие данные.

### Backup Script

`scripts/backup.sh` создаёт резервную копию содержимого исходного каталога.

### Backup Storage

Отдельный каталог, используемый как тестовое хранилище резервной копии.

### Restore Script

`scripts/restore.sh` восстанавливает данные из backup в отдельный каталог.

### Restore Target

Каталог, в который помещаются восстановленные данные.

## Security Considerations

Для реальной инфраструктуры необходимо отдельно учитывать разграничение доступа, защиту резервных копий, контроль успешности заданий, хранение нескольких поколений копий и регулярное тестирование восстановления. Данные пункты в этой лаборатории рассматриваются концептуально, без использования корпоративных данных.
