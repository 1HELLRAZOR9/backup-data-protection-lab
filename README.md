# Backup & Data Protection Lab

Практическая лаборатория по резервному копированию, проверке целостности и восстановлению данных.

## Цель

Отработать базовый инженерный процесс защиты данных:

1. подготовка тестовых данных;
2. создание резервной копии;
3. проверка наличия и целостности данных;
4. имитация потери исходных файлов;
5. восстановление из резервной копии;
6. проверка результата.

## Архитектура

```text
+----------------+       +----------------+       +----------------+
| Source Data    | ----> | Backup Storage | ----> | Restore Target |
| test files     |       | backup copy    |       | recovered data |
+----------------+       +----------------+       +----------------+
```

Лаборатория использует только тестовые данные. Реальные данные предприятия, имена пользователей, IP-адреса, сетевые пути и конфигурации в репозитории не используются.

## Запуск

Сделать скрипты исполняемыми:

```bash
chmod +x scripts/backup.sh scripts/restore.sh tests/test_backup_restore.sh
```

Создать тестовые данные и выполнить резервное копирование:

```bash
mkdir -p lab/source lab/backup lab/restore
echo 'security lab test data' > lab/source/example.txt
./scripts/backup.sh lab/source lab/backup
```

Восстановить данные:

```bash
./scripts/restore.sh lab/backup lab/restore
```

## Проверка

Автоматический тест проверяет полный сценарий backup → потеря исходных файлов → restore:

```bash
./tests/test_backup_restore.sh
```

Ожидаемый результат:

```text
PASS: backup and restore workflow works.
```

## Security Controls

- резервные копии хранятся отдельно от исходных данных;
- операции выполняются с тестовыми данными;
- перед восстановлением проверяется наличие backup-копии;
- результат восстановления проверяется после операции;
- реальные данные предприятия не публикуются в GitHub.

## Что отрабатывается

- Linux shell scripting;
- backup и restore workflow;
- контроль целостности и результата операции;
- базовые принципы Data Protection;
- автоматизация повторяемых операций;
- документирование процесса.

## Связь с работой Security Engineer

Резервное копирование является частью защиты доступности и восстановления данных. На практике Security Engineer должен понимать не только создание backup, но и весь жизненный цикл: требования к данным, разделение доступа, хранение копий, контроль успешности операций и регулярную проверку восстановления.
